# **App Name**: Halal Scanner

## Core Features:

- Barcode Scanning: Use the device's camera to scan product barcodes.
- Product Identification: Identify the product based on the scanned barcode using a tool and third-party API.
- Ingredient List Retrieval: Fetch the ingredient list of the identified product from a third-party API.
- Halal Check: Check the ingredient list against a database of non-halal ingredients to determine if the product is halal using a tool.
- Halal Status Display: Clearly display the halal status of the product (Halal/Not Halal/Possible Concerns).
- Ingredient Display: Display a formatted list of the ingredients.

## Style Guidelines:

- Primary color: Emerald green (#50C878), symbolizing growth and safety, crucial for conveying the reliability of the halal check.
- Background color: Very light green (#F0FAF3), provides a soft, clean backdrop that emphasizes content.
- Accent color: Warm orange (#FFA500), for warnings (if potentially haram ingredients are present) and actionable items.
- Body and headline font: 'PT Sans', a humanist sans-serif that provides a balance of modernity and warmth.
- Use clear and recognizable icons to indicate the halal status of a product. Icons should be simple, using recognizable symbols
- Prioritize clarity and simplicity. Information should be easy to find and understand at a glance.
- Use subtle animations to provide feedback after scanning, confirming ingredient checks.
